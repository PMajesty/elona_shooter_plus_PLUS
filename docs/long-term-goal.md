# Long-term browser-port goal

Updated 2026-11-02 at the user's request. This replaces older clock-rate,
watcher-pause and hitbox-priority wording in stored goals and historical notes.

Deliver a faithful, feature-complete modern browser port of Elona Shooter Plus
1.3.0.4 that runs on the user's website and remains practical to extend with
substantial additional content. Complete the original gameplay, campaign,
classes, town activities, items, progression, saves and website integration.
Preserve original English content, artwork, known rules and balance. Document
intentional fixes and remaining differences honestly.

Work solo in useful integrated slices. Favor feature coverage over exact
cosmetic, audio and incidental RNG-order matching when that precision would
delay playable functionality. Exact 30 Hz frames and 20 Hz ticks are optional
when observable gameplay remains faithful. Defer the reported late-game hitbox
complaint until core port coverage is complete; it is not a current priority.

Use automated deterministic/seeded scenarios, affected original comparisons,
save/restore checks and representative muted browser checks so the user need
not manually playtest builds. Keep testing proportionate; reuse unchanged
evidence. Preserve the user's save and the original SWF/ActionScript baselines.
Keep current-state documentation concise and push useful integrated checkpoints.

Completion requires original feature/content coverage with a finite documented
list of intentional differences, usable browser/save/hosting flows, and measured
correctness, stability and performance evidence. Tests alone do not establish
whole-game parity, balance or perfection. Do not declare completion while
required original systems are missing.
