# Browser release 1.1.0

- Expanded companion hits now show smaller, subdued damage numbers. Hero hits
  keep their original appearance. Pause has separate toggles for both.
- Companion numbers start enabled in Expanded, including existing adventures.
  Turning them off is remembered on Continue.
- Smart Mode now costs 25% damage. Its distance-based aiming delay has a 33%
  steeper gradient, with the existing 0.4-second maximum.

Classic defaults, styling and balance are unchanged. Saves remain compatible;
projectiles already in flight keep their damage at launch.

Refresh the [game](https://pastalapizza.site/elona/) to load the update.
