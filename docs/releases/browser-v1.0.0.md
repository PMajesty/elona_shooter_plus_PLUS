# Browser release 1.0.0

Play [Elona Shooter Plus in your browser](https://pastalapizza.site/elona/),
with desktop and touch controls and an English/Russian language toggle.

- Classic preserves the original game with the documented gameplay fixes.
- Expanded adds optional features, starting with Smart Mode for companions.
- Eight save slots, JSON backups and supported Flash-save imports are available.
- Russian includes menu artwork, descriptions and help. This release also fixes
  mixed-language battle news and trainer messages, and the day badge background.

Published with the developer's permission. Elona Shooter belongs to Noa;
credit for Plus and the original content belongs to its creators and contributors.
This is an unofficial, openly AI vibe-ported project. It is free and will never
be monetized. See [credits](../../README.md#credits) and [license scope](../../LICENSE.md).

The downloadable web build contains an `elona/` directory ready for static HTTP
hosting. Keep that path, or follow the [hosting guide](../../DEVELOPMENT.md).
GitHub's source archives contain the complete repository.

Browser adventures support Day 1–1000. Physical iOS/Android hardware and
historical player Flash saves remain unverified. The full
[faithfulness and compatibility notes](../../FAITHFULNESS.md) explain these limits.
