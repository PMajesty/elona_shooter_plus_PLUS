# Browser release 1.3.1

- Larger translucent Reload button for mobile, with a smooth outline and a clear gap beside the game.
- Compact option buttons with Auto / Авто above Reload. The battlefield stays centered in landscape.
- Reload can be queued up to 200 ms before the weapon is ready. Repeated taps keep the request without cancelling or restarting it.
- Separate indicators for queued and active reloads. A new firing gesture, weapon or item action, Auto change, or pause clears the pending request.
- English and Russian labels, with layouts for portrait and landscape screens.

Existing saves remain compatible with save v46. Desktop Space input and weapon
cooldown/reload timing retain their original rules.

Refresh the [game](https://pastalapizza.site/elona/) to load the update.
