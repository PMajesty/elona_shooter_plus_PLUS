# Browser release 1.3.3

- Added an optional **Reload on battlefield** setting in Guide. It places a small, translucent circular button within thumb reach in landscape. The compact side button remains the default.
- Remembered the setting on the device, separately from adventure saves. Portrait keeps the existing controls.
- Hidden the controls during loading so they no longer overlap the loading message.
- Fixed touches on the Guide changing game options behind it.
- Kept the compact controls visible on short landscape screens.

Existing saves remain compatible with save v46.

Refresh the [game](https://pastalapizza.site/elona/) to load the update.
