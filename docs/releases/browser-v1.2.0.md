# Browser release 1.2.0

- The browser client is now **Elona Shooter Plus+**, with the familiar logo.
- The title shows the browser release version instead of the original Flash
  version. It follows the package version automatically.
- The footer credits Noa and the Plus creators and contributors in English
  and Russian, replacing the original Elona RPG advertisement.

The source game remains Elona Shooter Plus 1.3.0.4. Gameplay and saves are
unchanged.

Refresh the [game](https://pastalapizza.site/elona/) to load the update.
