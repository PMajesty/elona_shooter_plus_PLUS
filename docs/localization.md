# English and Russian

The EN/RU button changes the current screen without restarting the adventure.
The preference belongs to the browser, independently of Classic/Expanded and
save slots. English strings remain canonical in simulation, saves and replays.

## Editing the translation

Opus translated and reviewed the catalogs in game context:

- `web/src/locales/ru-content.ts`: classes, skills, items, medals and generated descriptions.
- `web/src/locales/ru-ui.ts`: menus, events, help, errors and touch controls.
- `web/src/locales/ru-images.json`: original SWF text symbols, keyed by symbol ID.

Preserve numbered placeholders and newlines. A person named Smith and the Smith
upgrade have different translations; medal Prayer and the Pray action do too.
Use `contentText` for names and medal text, the default UI context for controls.
HP/AP/GP and keyboard keys retain their familiar abbreviations. Author names,
web addresses and brands are preserved.

Class names use the conventional masculine form regardless of appearance:
«Плут», «Дуэлянт». Keep their descriptions and awards consistent. The original
English uses she/her for these classes, but this does not restrict the portrait.
Do not add em dashes absent from the source. Rephrase Russian sentences naturally
and preserve the original decorative heading delimiters in artwork.

`localizedText` retains its source string. Constrained fields use
`fitLocalizedText` with measured bounds, a readable font floor and optional
ellipsis for compact names. Full descriptions remain in their tooltips.
Cropped text uses logical game coordinates, accounting for the canvas resolution.
Phaser 4's texture crop dimensions use pixels, but its draw offsets use game
coordinates. `localizedText` normalizes those offsets and reapplies the requested
crop when text or font changes resize the texture. The long-report browser check
verifies that scrolling never paints below the viewport.

## Artwork and fonts

`python tools/localize_web_assets.py --build` creates `web/public/assets/ru/`
from the preserved SWF and the derived XML generated by `extract_web_assets.py`.
It replaces text layers, preserves original geometry, and regenerates button
states, click masks and shadows. The bitmap Day badge is handled separately.
The English assets and original SWF are unchanged. Inspect the generated
`.build/localization/text-fit.json` and actual screens after wording changes.
This maintenance step requires the existing FFDec/Java extraction tools, Pillow
and OpenCV. To rebuild only the day badge's containing screens, append
`--only battle townHud townScene`; other existing exports are retained.

Russian uses [Neucha](https://fonts.google.com/specimen/Neucha) for handwritten
menus and [PT Sans](https://fonts.google.com/specimen/PT+Sans) for compact UI.
Their OFL license files are bundled beside the fonts in `assets/fonts/ru/`.
These fonts retain their own licenses, separate from the port code.

## Checks

Run `node --experimental-strip-types --test web/tests/i18n.test.ts` for catalog,
composition, storage, deterministic-save and artwork-footprint checks.
After building, run `node --experimental-strip-types web/scripts/localization-smoke.mjs`
against the local preview. It uses an isolated muted browser and checks live
switching, reload, New Game, combat/save/Continue, help, loot, skills, town and dialogs.
`QA_LANGUAGE=ru` also enables Russian in the existing mobile smoke script.
These checks do not modify the player's browser profile.

Single-line translation templates cannot consume adjacent news lines. The
results check combines real weapon/companion skill gains with the perfect-game
note so names and sentence punctuation remain intact.
